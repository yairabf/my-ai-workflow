# My AI Workflow

This repository is a home for reusable AI development workflows and the skills that support them. The goal is to make those workflows reusable across future software projects, including FlowRail and OpenHand.

Planned agent roles include planner, investigator, developer, reviewer, and QA. As each workflow takes shape, this repository will document when it runs, what each role receives and produces, how agents hand work off, and which skills they use.

## Install in a development repository

[Engineering Workflows](engineering-workflows/README.md) installs the
Initiate and Investigator skills into a target Git checkout for Pi, OpenCode,
Claude Code, and Codex. Follow the pack's installation and development
workflow to prepare the target and start its first investigation.
